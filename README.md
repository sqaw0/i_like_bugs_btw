# i like bugs btw

Клиентский Fabric мод, автоматизирующий использование **F** при нажатии на ПКМ.

## Функцонал

 - При нажатии на ПКМ, одновременно использует и свапает предмет, воиспроизводя эффект *гостинга* (ассинхронизации).
 - Имеет переключатель на клавишу С (разрешаю менять в настройках).
 - При переключении появляется плашка.
 - Ну и всё.

## Как работает

Использует **Mixin's** для перехвата `Minecraft.handleInputEvents()` и вызова `KeyMapping.click()` (т. к. если делать данную штуку с левой рукой, шанс гостинга уменьшается в разы).

## Установка

1. Скачай [Fabric API](https://modrinth.com/mod/fabric-api).
2. Скачай `.jar` нужной версии из [Releases](https://github.com/sqaw0/i_like_bugs_btw/releases).
3. Положи эти файлы в папку `mods`.
4. Запусти игру.
